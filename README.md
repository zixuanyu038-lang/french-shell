# French Shell / 法语词壳

前端展示名为「D指导法语」：查词、生词本和自带接口的本地工具，配一个网络上已有的 DeepSeek 娘 / 蓝色大肥鱼作为非官方学习搭子。界面使用紧凑的蓝白工作台和简短口语文案；操作、密钥风险、错误和费用提示仍直接说明。

D指导只保留「高清小鱼」，使用同一张现成 4×4 图集里的固定姿态。默认静止；查词时思考、出结果时讲解、保存成功时庆祝、失败时低落。点「戳一下」短暂显示挥手姿态，1.5 秒后恢复当前业务状态；不随机轮换、不追鼠标、不自动吃饭或打盹。角色可收起或隐藏，业务提示优先；装饰互动不改气泡文字，新查询会立即结束旧互动。只加载一张本机图片，不调用 LLM/TTS；朗读姿态不是精准口型。

仓库自带当前使用的高清小鱼原图和完整上游许可，克隆或下载 ZIP 后无需另外找图，不依赖图片外链。角色素材作者：YunYueSama；仓库：https://github.com/YunYueSama/codex-deepseek-pet 。图片未修改，依照上游「大肥鱼项目署名许可 1.0」分发作者有权授权的贡献，不属于本项目 MIT 许可证；底层角色、参考作品与标志的第三方权利仍按上游声明保留，不代表 DeepSeek 官方授权。来源、校验值与许可边界见 [ASSET_SOURCES.md](ASSET_SOURCES.md)。其他历史研究素材不随仓库发布；当前图集缺失时仍能查词，不自动联网下载。

本地优先的法语学习工具，目标是支持用户自带 LLM 与 TTS API Key。

## 当前版本

支持离线演示和真实 API 查词：拼写纠正、歧义候选、按词性展示词卡、收藏/不会、本地生词本、标为熟悉、过滤、删除、JSON 导出、词句与选区朗读入口。大屏工作区随窗口展开，正文、控件和 D指导形象提高默认尺寸，不依赖浏览器缩放。

LLM 和百炼 TTS 请求接口已实现，真实供应商联调需要用户 Key。离线演示支持 `manger / mangeais`、`maison`、`heureux / heureuse`、`bonjour`、`sale`、`salle`；错拼示例 `bonjure`、`maizon`、`mangais` 与歧义示例 `sall`。无查询历史，无音频文件保存。词库默认在浏览器 IndexedDB 中，也可连接用户选定的 JSON 文件；清除站点数据会删除浏览器词库，不会删除另存的 JSON 文件。

纠错会显式显示原输入和推测的正确形式；多候选先让用户选，不默认选第一条。最多 3 张完整候选卡在同一次请求返回，切换不再调用 API；发音和保存只使用选中卡。外层原始查询字段及纠正提示只保留在本次页面内存，保存的是所选词卡快照，不另存这些字段。提示词要求词卡正文不引用原始错拼，但模型仍可能在正文中提到原输入，文本须人工核对。模型也可能猜错；未识别时不凑词卡，结构校验不保证法语知识正确。

## 法语朗读

朗读属于实验功能，默认关闭，目前音频质量尚未达到法语学习的预期。设置页可配置接口地址、Qwen HTTP 模型、音色与语言。启用后填写与接口地域对应的 Key、应用设置再试听。默认预设 `qwen3-tts-flash`、`Cherry`、`French`，不是强制值；当前适配器不支持其他供应商协议或 realtime 模型。参考 [官方接口与音频格式](https://help.aliyun.com/zh/model-studio/qwen-tts-api)。

使用 HTTP SSE 流式输出，收到 Base64 PCM 后立即由 Web Audio 调度播放：24 kHz、单声道、16-bit little-endian。请求经本机代理转发，音频不写磁盘、不进入词库、无重复播放缓存；每次点击重新请求。单次选区上限 500 字符，生成超时 30 秒。点击另一处会取消旧请求、停止旧音频。后端不会为 TTS 自动重试，避免重复请求。

播放栏显示首段安排播放耗时（从点击到调度首段音频，含约 25ms 缓冲，不代表扬声器实测延迟）与合成完成耗时。实际延迟由网络、百炼服务和浏览器音频设备共同决定。测试覆盖模拟流，尚需真实 Key 验证账号权限、音色效果和速度。

在“设置”选择真实 API 模式，填写服务地址、模型名和 Key，应用设置后查词。默认 DeepSeek 地址为 `https://api.deepseek.com`，模型 `deepseek-flash`，关闭思考模式。参考 [官方调用说明](https://api-docs.deepseek.com/zh-cn/) 与 [JSON Output](https://api-docs.deepseek.com/zh-cn/guides/json_mode/)。其他兼容服务需支持 `/chat/completions`、`response_format: json_object` 与 `max_tokens`；兼容模式不会发送 DeepSeek 专有参数。参数支持因供应商和模型而异。

API Key 默认仅保留在页面内存中，不输出日志、不加入词库或导出。可主动勾选“记住本次填写的密钥”并应用：查词与 TTS 分开保存，默认文件位于当前系统用户目录下 `.french-shell/credentials.json`（项目外）。它是明文配置，不是加密保险箱；拥有本机账号/文件权限的程序可读取，Windows 权限继承当前用户目录，POSIX 新建文件使用 0600。不要共享或上传此文件。可用环境变量 `FRENCH_SHELL_CREDENTIAL_FILE` 指定其他私有位置；若放入项目必须确认 Git 忽略，默认文件名及临时文件已忽略。

保存操作明确绑定规范化后的 HTTPS 接口地址，查词还绑定接口类型；改地址或类型必须重新填写并确认。模型、音色变化不需要重新保存。前端只读取已配置状态和绑定信息，不回显密钥；请求时由后台注入。输入了临时 Key 时优先使用临时 Key，不自动覆盖已保存内容。取消勾选不会删除既有密钥，删除须点击专用按钮；删除清除本页密钥，不影响生词。删除不是磁盘安全擦除，也不撤销供应商密钥，已经发出的请求可能继续完成。

非敏感设置在浏览器保留；保存密钥后刷新无需重填，刷新不会自动发送供应商 API 请求。服务只监听 127.0.0.1，并校验 Host 与请求来源，密钥管理强制同源 POST。本机服务解决供应商 CORS 限制，当前版本不应直接作为公网服务部署。同源恶意脚本或本机程序不在此防护范围内。

## 存储位置与备份

设置页支持两种词库存储：

- 浏览器本地：默认使用 IndexedDB。位置由浏览器管理，网页无法指定磁盘目录。
- 用户选择的 JSON 文件：使用 File System Access API，通过系统文件选择器指定文件位置。每次收藏或修改学习状态自动更新该文件。浏览器不提供完整磁盘路径，页面显示文件名。权限失效时由用户点击重新连接，不在刷新时自动弹权限框。

不支持文件选择 API 的浏览器仍可导入/导出 JSON。下载目录由浏览器管理。新建文件会复制当前词库，已有非空文件不会被覆盖；打开已有词库会先校验格式。切换存储保留原数据，不自动合并。导入按原形与词性去重，并保留更新时间较新的记录。

数据库升级、打开与事务均有错误处理；刷新时取消查词和音频请求、释放音频设备与数据库连接。前端查词 50 秒、语音生成 35 秒、音频设备启动 5 秒超时，不应无限等待。此前内置浏览器标签无响应的具体根因尚未复现，需继续实机观察。

模型返回 JSON 后进行字段校验，格式无效时仅重试一次；HTTP 错误不自动重试。每次查询总超时 45 秒，支持手动取消。AI 生成内容在词卡标明来源。格式校验不保证法语知识正确。

## 启动

安装 Node.js 20 或更高版本，无第三方运行依赖。下载仓库 ZIP 后先解压，进入包含 `package.json` 的项目目录；不要直接双击 `index.html`。

```sh
cd french-shell
node server.mjs
```

打开 http://127.0.0.1:4317 。也可用 `npm run dev` 启动；不必先运行 `npm install`。测试：`node --test` 或 `npm test`。

首次启动默认演示模式，可以直接看到相同的页面、高清小鱼及样例词卡。真实查词和 TTS 需使用者填写自己的接口与 Key；你的密钥、生词本、浏览器偏好和个人数据不随仓库复制。这是本地 Node 应用，上传 GitHub 不等于部署网站，GitHub Pages 不能运行本机后台。

端口通过环境变量 `PORT` 配置。默认预设集中在 `src/settings.js`，用户可在界面修改。源码不包含绝对工作目录或用户 Key。`.gitignore` 排除 `.env`、本地数据目录和日志；`.env.example` 仅说明可用环境变量，不会自动加载。准备 GitHub 仓库时应仅包含本项目目录，避免把上级个人学习资料一起发布。

## 数据约定

`src/lookup.js` 定义查词外层 schemaVersion 2 的匹配、纠正、歧义和未识别状态。`src/entries.js` 保留词条 schemaVersion 1 及旧生词兼容；`lemma` 与 `ipa` 属于原形，`query` 与 `queryIpa` 属于识别或纠正后的实际词形。动词必须分别标记语式和时态。未知值用 null；无适用词形或变位用空数组。词库按 `原形 + 词性` 去重，“收藏”和“不会”是独立属性。保存所选文本词条快照，不保存音频或全部候选。
