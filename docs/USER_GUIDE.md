# French Shell 使用说明书

界面名：D指导法语。适用版本：0.1.0 本地原型。更新：2026-10-03。

## 1. 这是个什么工具

一个本地优先、用户自带接口的法语查词工具。D指导是 DeepSeek 娘 / 蓝色大肥鱼的非官方同人形象，不代表 DeepSeek 官方产品。

你可以查词、看词形与变位，把不认识或喜欢的词留下，点击词句或选区朗读。查词不是完整聊天；模型按约定格式生成词卡。

当前没有账号、云同步、查询历史、音频缓存、背词算法或学习积分。课文生成、整篇跟读、听写和桌面全局划词仍是后续功能，不是已实现功能。

## 2. 第一次启动

需要 Node.js 20 或更高版本。项目没有第三方运行依赖，不必先执行 npm install。

在终端进入项目目录，执行：

```sh
cd french-shell
node server.mjs
```

打开 [本机页面](http://127.0.0.1:4317/)。终端必须保持服务运行；只打开网页而不启动服务不能使用后台接口。结束服务时在终端按 Ctrl+C。

仓库已包含高清小鱼原图，不需要额外下载图片。若下载 ZIP，先解压并进入包含 `package.json` 的目录再启动；直接双击 `index.html` 不是支持的启动方式。第一次默认演示模式，可看到同样的页面和角色，真实接口需要填写自己的 Key，个人生词和设置不会随源码复制。

启动不产生供应商费用；刷新页面也不会自动调用 LLM 或 TTS。

端口默认 4317，可用环境变量 PORT 修改。例如 PowerShell：

```powershell
$env:PORT = '4318'
node server.mjs
```

`.env.example` 是说明文件，不会自动加载。不要在项目文件里写真实密钥。

## 3. 先试演示模式

无需 Key。点击首页样例，或输入 `manger`、`mangeais`、`maison`、`heureux`、`heureuse`、`bonjour`、`sale`、`salle`。

也可体验错拼：`bonjure` → `bonjour`，`maizon` → `maison`，`mangais` → `mangeais`。输入 `sall` 会出现 `sale` 和 `salle` 两个候选。

演示词卡是固定样例，不调用模型。其他词会提示演示模式不支持，而不是自动使用真实接口。

## 4. 配置真实查词

进入「设置 → 查词接口」：

1. 查询模式选「真实 API 查词」。
2. 选择接口类型。DeepSeek 类型发送关闭思考参数；兼容类型不发送 DeepSeek 专有参数。
3. 填服务地址、模型 ID 和对应 Key。服务地址必须是 HTTPS，不能带用户名、密码、查询参数或 URL 片段。
4. 点击「应用查词设置」，回查词页输入词语。

默认 DeepSeek 预设为 `https://api.deepseek.com` / `deepseek-flash`。这是可修改的代码预设，不是“任何时候最快”的保证；账号、网络、模型负载与输出长度都会影响速度。

兼容服务要支持 `/chat/completions`、JSON Object 输出和当前请求参数。例：供应商要求 `/v1/chat/completions` 时，服务地址填到 `/v1`，不要再填写完整 `/chat/completions`。供应商的“支持 OpenAI 协议”不保证所有模型支持 JSON 参数。

### 密钥要不要每次填写

- 不勾「记住」：只在当前页面会话使用，刷新或重开后清除。
- 勾「记住本次填写的密钥」并应用：保存到本机后台，下次打开同一接口无需重新填。
- 页面不会回显已保存的 Key，只显示已配置状态。保存成功后输入框清空。
- 已保存密钥绑定接口地址；查词还绑定接口类型。改地址/类型要重新填写确认，不能把旧 Key 自动发给新服务。
- 换模型、音色不要求重新保存 Key。临时输入新 Key 不会自动覆盖原来保存的 Key。
- 不再勾选「记住」不等于删除；须点「删除已保存的查词密钥」或「删除已保存的 TTS 密钥」。

默认后台文件：当前系统用户目录里的 `.french-shell/credentials.json`，在项目目录外。可通过环境变量 `FRENCH_SHELL_CREDENTIAL_FILE` 改到另一私有位置。

它是明文文件，不是加密保险箱；不要分享或上传。同一个系统账号、同一个本机服务的页面可能使用这些保存的密钥，当前没有多用户隔离。删除本机 Key 不会撤销供应商的 Key；撤销须去供应商控制台。

## 5. 如何看词卡

| 内容 | 含义 |
| --- | --- |
| 大标题与音标 | 单词原形及原形发音 |
| 中文释义 | 一到两个核心意思 |
| 识别形式 | 模型识别或纠正后的词形、该词形的音标和语法分析 |
| 名词信息 | 阴阳性、冠词与复数等 |
| 形容词信息 | 阴阳性、单复数对应形式 |
| 动词信息 | 组别、助动词、分词及默认现在时变位；输入形式的语式/时态/人称 |
| 例句与提示 | 一个简单语境和简短学习提示 |

例如 `mangeais` 的原形是 `manger`，两者的音标不是同一个。看「识别形式」避免把原形发音误当成变位发音。动词变位表可展开。

### 拼错了怎么查

- 输入可识别时直接显示词卡；同一拼写有不同词性时可列出多个用法。
- 推测目标较明确时，页面显示原输入 → 纠正后的形式，再展示对应词卡。不静默替换输入。
- 有多种合理可能时，最多给 3 个候选，先选择再展开；不会默认认定第一项正确。完整候选在同一次模型请求中返回，切换候选不再调用 API。
- 没有合理目标时只给未识别提示，不凑词卡。可改拼写或补充法语上下文。

纠正仍是模型推测，不保证语义正确。有效词和合法变位应优先原样分析，不能把 `sale` 强改成 `salle`，也不能把合法的 `mangeais` 当错拼。

朗读按钮使用选中词卡的识别形式、原形、词形或例句，保存操作写入所选词卡快照。外层原始查询字段和纠正提示只保留在本次页面内存，不另附入生词记录；提示词要求词卡正文不引用原始错拼，但不能保证模型正文永不提到原输入，保存前仍需核对文本。只有主动点“不会”或“收藏”才存所选那一条，不会保存全部候选。拼写提示区域不提供选区朗读。

AI 结果会标明模型来源。格式校验只能确认字段结构，不能保证释义、音标和变位全部正确；有疑问应核对词典。

查词按钮旁显示等待秒数，可点「取消」。返回结果后展开耗时信息，可看请求模型、服务返回模型、接口耗时、端到端耗时与调用次数。

查词失败的具体原因会留在搜索框下方，开始下次查询时清除，不只是一闪而过的通知。切换查词、生词本和设置时回到页面顶部。

查词请求是流式传输：进度条会实时显示已生成的字符数，模型写出原形后先显示词头，不用干等。词卡正文仍要等整条 JSON 校验通过后才渲染，不是逐字聊天流。纠错和词卡在同一次请求完成，不增加专门的纠错预请求；多个完整候选可能使输出时间变长。未识别结果也发生了本次模型调用。后端总超时 45 秒；格式不合约定最多再请求一次，因此一次操作可能产生两次模型调用。HTTP 错误不自动重试。前端等待上限 50 秒。

D指导的气泡全部是本地状态反馈；复习提示会带上当前单词原形，不会额外生成聊天回复或增加模型请求。完整学习提示放在词卡中，不在角色气泡重复。页面文案更口语化，查词、保存和取消等按钮仍直接说明操作；密钥、费用和权限提示不会用梗代替。

### D指导的形象与动效

现在只保留「高清小鱼」，不再提供形象选择或动作菜单。取消「显示 D指导」并应用可隐藏角色。「收起 / 展开」可缩起角色区域；显示偏好会在当前浏览器保留。旧版本的其他形象偏好会自动归一到高清小鱼。

默认固定站好。查词时托腮思考、出结果时张臂讲解、保存成功时庆祝，失败时低落；取消回到待机。从生词本打开词卡会进入思考姿态的复习状态。朗读使用讲解姿态，不是跟随音频的精准口型。所有姿态取自同一张高清图，避免切换画风或服饰。

点击「戳一下」只显示同一个挥手姿态，1.5 秒后回到当前查词状态，不连续逐帧挥手。连续点击只保留一个恢复计时器。查词、朗读及错误状态不接受装饰互动；新查询会结束旧互动，不覆盖新结果或气泡文字。没有首次自动问候、随机小动作、鼠标环视或自动打盹。

当前全部是静态姿态，没有默认循环动画，也不再需要动效开关。系统开启减少动态效果时同样不会逐帧播放。页面在后台、角色收起或离开查词页时暂停这一次反馈的倒计时；返回后仅显示剩余时间，不重新开始完整互动。期间收到新查询则取消旧互动。

只加载随仓库提供的 `deepseek-actions.png` 一张 2048×2048 原图，不再加载其他动作文件。加载失败显示文字提示，不换另一套角色，不影响查词或生词本。素材只从本机读取，不自动访问 GitHub 下载。图片作者为 YunYueSama，采用独立的上游署名许可，不属于源码 MIT 许可；来源与第三方权利限制见 [素材说明](../ASSET_SOURCES.md)。

## 6. 保存与复习生词

查完后点击「＋ 不会」或「☆ 收藏」，词才会进入生词本。只查询但不点击保存，不留查询历史。

生词本自动按词性分组：名词、动词、形容词、副词、代词、限定词、介词、连词、感叹词、短语，只显示有词的分组。每组显示当前可见数量，组内按最近更新时间排序。

默认显示全部词性；使用「词性」下拉框只看一类，也可同时输入原形、查询词或中文释义进一步过滤。筛选后会显示“显示 X / Y 个词”，总词数不因筛选变化。没有匹配时可以点击「清除筛选」恢复全部。

点击词名重新打开已保存词卡，不必重新调用 LLM。可以标为熟悉/不会，或删除。分类读取词卡已有的 partOfSpeech，不额外调用模型，不重新生成词条；存储和 JSON 备份仍是 schemaVersion 1，已有生词和旧备份无需迁移。浏览器中的异常词性值归入「其他 / 未分类」，不因此丢弃词条；导入仍遵守原有词条校验。

「不会」和「收藏」是独立标记。去重规则是“原形 + 词性”：同一动词不同变位通常共用一个记录，不是把每个变位都存一遍。重新保存会更新该词卡快照，不保留旧版本历史。

删除词条目前没有回收站，需要提前导出备份才能恢复。没有自动复习计划或遗忘曲线算法。

## 7. 选择词库存储位置

### 浏览器本地（默认）

词库保存在 IndexedDB。网页不能替你指定其磁盘目录。清除网站数据、更换浏览器或进入另一浏览器配置，不会看到原来同一个词库。

浏览器数据跟随站点来源：换端口也是另一个来源，非敏感设置和词库可能看起来“丢了”，其实仍在旧来源。迁移前先导出。

### 用户选择的 JSON 文件

在「设置 → 数据与存储」：

- 「新建数据文件」：选择位置，复制当前词库到新文件；已有非空文件不会直接覆盖。
- 「打开已有词库」：选择有效的 French Shell JSON，切换到该文件作为当前词库。
- 后续收藏、改学习状态或删除会更新该文件，不是只导出一次。
- 页面只显示文件名，不显示完整磁盘路径。刷新后权限失效，点「重新连接文件」授权。
- 「使用浏览器词库」：回到原来的浏览器词库，不删除所选 JSON 文件。

只有支持 File System Access API 的浏览器能连接文件；不支持时相关按钮不可用，但仍可导入/导出。

切换位置不会自动合并两个词库。文件写入在单个页面内排队；没有跨标签/跨进程冲突合并机制，同一词库文件避免同时在多个页面或其他软件里编辑。

### 备份与迁移

导出 JSON 后自行选择备份位置。下载目录取决于浏览器设置。

导入支持本项目 schemaVersion 1 的备份，上限 5 MB、10,000 条输入记录；按原形与词性合并，保留更新时间较新的记录。导入时不会调用模型。

备份不包含 API Key、接口设置或音频。迁移电脑时，词库和接口配置要分别处理，不要把密钥当成词库附件发送。

## 8. 法语朗读（实验功能）

进入朗读设置，勾「启用 TTS」，填写接口、模型、语言、音色、Key 后应用。Key 可另行主动保存。

当前仅适配阿里云 Qwen HTTP 流式接口；不代表已支持所有 TTS 供应商，也不支持 realtime 协议。默认模型 `qwen3-tts-flash`、语言 `French`、音色 `Cherry`，可修改为接口支持的值。账号权限与 Key 地域须匹配服务地址。

可点「试听 Bonjour」，点击词卡上的朗读按钮，或在词卡/生词本选中法语文本后点「朗读选中的法语」。这不是系统全局划词：其他网页和应用里的选区不在支持范围。

每次点击重新请求 TTS，不缓存音频、不写音频文件。单次最多 500 个字符；点击另一处会停止并取消之前的播放，也可点「停止」。停止本地请求不保证撤销供应商已经发生的计费。

首段耗时是安排首段音频播放的时间，不是实测扬声器延迟。后端生成超时 30 秒，前端请求上限 35 秒，音频设备启动上限 5 秒。

当前法语语音质量仍待改进，所以默认关闭。换网页主题和角色不会改变音频质量；不建议将它当成唯一标准发音来源。

## 9. 常见问题

| 问题 | 检查方法 |
| --- | --- |
| 页面打不开 | 先确认 node server.mjs 在运行，URL 端口与终端一致 |
| 演示模式查不到词 | 改用支持的样例，或应用真实接口设置 |
| 改了 Key 仍不生效 | 输入后要点击对应「应用」；接口地域、地址、模型和账户权限都要核对 |
| 刷新后没 Key | 确认此前主动勾选记住并成功应用；接口地址/类型改动后旧密钥不再匹配 |
| 文件需重新授权 | 点「重新连接文件」，不要清除站点数据 |
| 词库打开卡住 | 关闭占用旧数据库的标签后重试；仍失败先保留数据，不要直接清站点 |
| 生词本突然为空 | 检查浏览器、端口、过滤文字及当前存储模式 |
| TTS 不发声 | 确认已启用并应用；检查 Key、浏览器声音权限、设备和接口错误提示 |
| 语调奇怪 | 属于尚未解决的音频质量问题，不等于一定是流式传输导致 |
| D指导没有图片 | 确认完整解压、图集文件未被删除，使用本机服务启动；查词功能仍可用 |

此前内置浏览器刷新后无响应的根因没有明确复现。已有超时、取消及资源释放处理，但不能承诺所有浏览器卡顿都已根治。

## 10. 隐私与开源边界

后台只监听 127.0.0.1，不应该直接部署成公网服务。LLM 会收到待查文本，TTS 会收到待读文本；使用供应商 API 仍意味着相应文本会发送给服务商，不是“全部离线”。

词库、非敏感设置和密钥分别保存。敏感 Key 不进入源代码、生词文件或导出备份。上传 GitHub 前仍需人工检查文件内容；Git 忽略规则不能替代发布审查。

只发布 french-shell 项目目录，不把上级个人学习资料一起发布。源码采用 [MIT](../LICENSE)，当前图集按独立上游署名许可随仓库提供，不随代码改成 MIT，且不宣称替代底层角色与参考作品的权利，见 [素材说明](../ASSET_SOURCES.md)。
